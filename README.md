Place in Space — це інтерактивний 3D-вебзастосунок для вивчення астрономії, який перетворює складну теорію та формули з підручника на зрозумілий візуальний інструмент. Користувач може самостійно керувати космосом, змінювати параметри орбіт і в реальному часі спостерігати за рухом планет.

Основні розділи проєкту:
1. Закони Кеплера
2.Екскурс Сонячною системою
3.Конфігурації планет

Технологічний стек:
Backend: Python
Frontend:HTML, JavaScript
3D-графіка:Three.js
